動作モード

マスキングがオンのときの背景色

マスキングがオンのとき、チャットの背景にこの色を薄く混ぜます。オンかオフかがひと目で分かります。 色見本の左は明るい表示、右は暗い表示で実際に付く色です。

背景色は目印で、保護されていることの保証ではありません。サイトは自分の画面の色を自由に変えられるので、 正しい状態は入力欄のそばの PII Guard のアイコンで確かめてください。

ローカル LLM 連携 v0.5.0 dev

Ollama / llama.cpp / LM Studio 等の OpenAI 互換 API を指定すると、 正規表現・形態素解析に加えて LLM による文脈考慮型 PII 検出が有効化されます。 URL 未設定時は従来通りローカルエンジンのみで動作します。

未設定
未インストールのモデルは右の「ダウンロード」で Ollama へ pull できます。 精度目安は PII 検出タスクでの相対評価 (内部ベンチマーク) です。

ブラウザ内 ML 検出 v1.3.0

BERT-NER モデル (DistilBERT-multilingual, ~135 MB) をブラウザに常駐させ、regex / 辞書では取れない人名・地名・組織名を文脈から検出します。 外部 LLM サービスやゲートウェイ不要で完結し、すべての推論は端末内で実行されます。

ステータス 未有効
モデル Xenova/distilbert-base-multilingual-cased-ner-hrl

初回有効化時に Hugging Face Hub からモデル (約 135 MB) を取得します。 ブラウザの IndexedDB にキャッシュされるため 2 回目以降は秒で起動します。 無効化してもキャッシュは保持されます (再有効化が早くなる)。

現在 ML 検出は standalone モード のみで動作します。Docker ゲートウェイが起動中の場合はゲートウェイ側の Sudachi/Presidio が優先されるため、ML を試したい場合はゲートウェイを停止してください。

動作ログ

PII Guard が何をしたかの記録です。たとえば、送信を伏せ字にした、通信を止めた、入力欄のアイコンへのクリックを受け付けなかった、など。 端末の中に 14 日分だけ残し、それより古いものは自動で消します。外部には送りません。

入力した文章、見つけた値、ファイル名、送信の中身は記録しません。不具合を伝えるときは「コピー」を押して、その内容を貼り付けてください。
