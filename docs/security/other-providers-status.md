# ChatGPT 以外 (Claude / Gemini / Manus) の保護状況

> 2026-10-18 / 対象: feat/secure-composer
> 確認スクリプト: `tests/integration/verify-other-sites.mjs` (送信前の漏れ)、`tests/integration/dryrun-send.mjs` (送信・添付の空送信)
> 計画: `plans/fix-egress-leaks-2026-10-18.md`

## 1. 確認方法

- 拡張を読み込んだ実ブラウザ (ログイン後) で確認した。**メッセージは送っていない。**
- **送信前:** 入力欄に架空の個人情報とカナリアを打ち、次の操作ごとに数秒ずつ通信を見た (全タブ・iframe・Worker・Service Worker のリクエストと WebSocket の送信)。
  1. 打ち終わり
  2. フォーカスを外したあと
  3. 下書きの入った入力欄をクリックしたあと
- **送信・添付 (空送信):** 実際に Enter や添付をして、出ていく通信を全部その場で止め、止めた本文を調べた。止め方は 3 段。
  1. ページの fetch / XHR / sendBeacon / WebSocket を、拡張のフックより下で止める。拡張がマスクした後の本文を受け取れる。順番はテスト送信で毎回確かめる。
  2. CDP の Fetch で、ネットワークに出る直前に止める (1 をすり抜けた経路の受け止め)。
  3. 送ったあとは読み直して、保存された分の送り直しも見張る。

  どの回も、外に出た通信は 0 件 (CDP の記録で確認)。
- 本文は、protobuf を入れ子まで分解し、圧縮・UTF-16・Base64・WebChannel の中も見た。

## 3. 安全網 (F-EG-03/04): サイトが形を変えても素通しにしない

- 利用者が打った・貼った文字から検出した値 (常に伏せる語を含む) を覚えておく。
- 送信アダプタが扱わなかったすべての通信を、どの宛先・どの経路 (fetch / XHR / sendBeacon / WebSocket) でも調べる。その値が入っていれば、文字の本文は伏せ字に置き換え、置き換えられない形は止める。
- 外部 (サイト自身以外) の宛先は、下書きの一部 (16 文字以上の連続) が入っているだけでも止める。個人情報と判定できない名前や機密も、解析ツールに出さないため。
- 外部宛てを止めたときは「送れた」(200) と返す。解析ツールがイベントを保存して送り直し続けないようにするため。
- 覚えた値は `chrome.storage.session` にサイトごとに 30 分残す (メモリだけ、ブラウザを閉じると消える)。読み直しの後に解析ツールが保存しておいたイベントを送り直しても、止められる。
- 止めた・伏せたときはピルが知らせる。
- 今回の LK-01/02 のように送信の形が変わっても、送信の本文に検出済みの値が入っていれば止まる。素通しではなく「送れない」側に倒れる。

## 4. 残る限界

- **問い合わせによる推測 (V-02 の残り):** ページは任意の文をマスクさせて、ある語がリストにあるかを 1 語ずつ試せる。マスクの結果はページの通信に載るので、ページ側でマスクする方式では避けられない。Secure Composer を各サイトへ展開すれば塞がる (入力をページに見せない)。
- **検出できない個人情報:** 安全網は検出した値を探す。外部宛ては下書きの一部 (16 文字以上) も止めるが、サイト自身宛ての、検出できない短い名前などは通る (送信のマスクと同じ限界)。
- **画像・PDF などのバイナリ:** マスクできないので、マスキング ON では添付・貼り付け・ドロップのどれでも止める (ChatGPT と同じ方針)。スクリーンショットの貼り付けも止まる。
- **OS からの本物のマウスドラッグ:** 自動化では CDP で再現した。手での確認を 1 回してもらうのが確実。
- **サイトの変化:** 送信の形はまた変わりうる。変わったときは安全網が止めるので漏れはしないが、送れなくなる。`tests/integration/dryrun-send.mjs` で早めに気づける。

## 5. 再確認の手順

1. 拡張を読み込んだ Chrome を `--remote-debugging-port` 付きで起動し、各サイトにログインする。
2. 送信前の漏れ: `node tests/integration/verify-other-sites.mjs <site> --wait-login=600`
3. 送信・添付の空送信: `node tests/integration/dryrun-send.mjs <site> [--attach=<file>] [--drop=<file>] [--paste=<file>]`
   - テスト用ファイルは架空の値だけにする。名前か中身に `PIIGUARDFILE` か `山田太郎` を入れておくと、マスクに失敗しても止め具が止める。
4. 拡張の SW を更新したときは注意する。`--load-extension` で読み込んだ拡張は、Chrome を再起動しても SW のスクリプトが入れ替わらない。テスト用プロフィールなら、閉じた状態で `Default/Service Worker` を退避してから起動する。
